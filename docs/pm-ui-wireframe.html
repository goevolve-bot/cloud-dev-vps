  1. 1 Project selector; last entry is “+ add project…” → modal below. Daemon state shown per project.
  2. 2 Tabs, not a dropdown: Tasks / Specs / ADRs — all read from the repo’s .pm/ dir.
  3. 3 Search over the cached index of tasks + specs + ADRs in the current project.
  4. 4 Project daemon badge: active / idle / stopped; click → toggle, “always on” pin.
  5. 5 Status groups = folders in .pm/tasks/; collapse per group; live dot on tasks with a running agent.
  6. 6 Launch bar: phase × provider × model. Quick buttons launch other phases with project defaults.
  7. 7 Markdown editor: paste image → attachment; huge text paste → pasted-NN.md attachment (as in Claude chats); explicit “+ attach” for files. All stored under the task folder in the repo.
  8. 8 Timeline mixes status moves, comments, and runs — each backed by a file in the task folder; newest at the bottom, composer fixed below.
  9. 9 Running agent: live log tail via SSE (from pm data dir, not the repo); stop button; full raw log on click.
  10. 10 Verify artifacts: screenshot thumbnails + GIF/video inline; click → lightbox.
